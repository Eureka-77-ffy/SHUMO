# 六篇国一论文框架图对标记录

## 对标对象

1. 南京邮电大学 A 题：每一问采用“几何关系—方程联立—递推/搜索—坐标输出”的横向算法链，优点是步骤与方法紧邻。
2. 南京林业大学 B 题：总体分析以文字论证为主，局部图形服务于决策与概率解释；说明框架图必须承担独立信息任务，不能只作装饰。
3. 南京信息工程大学 B 题：使用分阶段彩色底板，将“提出假设—两种方法—方案比较”放在一张图内，阶段边界醒目。
4. 扬州大学 C 题：由共同输入向不同问题分流，并把方法、约束、求解与结果按纵向链展开；优点是输入依赖和问题关系清楚。
5. 江苏海洋大学 C 题：问题分析依赖正文解释，局部算法图用于求解过程；说明复杂图仍需与正文叙事形成互补。
6. 江南大学 A 题：顶部展示问题递进，向下列出每问关键机制和输出，评委能快速建立全文地图。

## 吸收的结构原则

- 第一眼先看到四问关系，而不是一排软件步骤。
- 共同输入必须汇入统一物理内核，避免四问看成互不相干的模型。
- 每问至少同时给出新增机制、求解动作、时域或判据、题定输出。
- 用连接线明确 Q2→Q3 是状态轨迹接续；Q1、Q2、Q4 均从原始初态独立计算。
- 验证不是尾部一句话，而是数值、输入参数、结构边界三条并列证据链。
- 颜色只承担必要强调：深蓝灰用于结构和连接，金色仅用于状态接续与临界结果。

## 不采用的做法

- 不复制参考论文的具体图元、文字或配色。
- 不使用单向横排六个盒子的“流水账”结构。
- 不把 Q3 与 Q4 画成同一状态轨迹的连续计算。
- 不加入与论文无关的装饰性图标、3D 元素或无语义箭头。
