# fig00a visual spec

## 设计目标

- 风格：顶会论文常见的克制型方法框架图，而非彩色信息海报。
- 画布：1400×405 横版；正文整栏嵌入。
- 信息原则：一张图只回答四件事——输入是什么、共享什么、四问如何关联、如何验证。

## 视觉语言

| 角色 | 颜色 |
|---|---|
| 主结构与连接 | #314E73 |
| 正文 | #252A32 |
| 次要说明 | #697482 |
| 线框与分隔 | #AEB7C2 |
| 浅底 | #EEF3F8 / #F6F7F9 |
| 唯一强调 | #B88A3B |

- 无渐变、无阴影、无图标、无大标题、无编号旗标。
- 金色只用于 Q2→Q3 状态接续和 Q3/Q4 临界时间。
- 字号收敛为 18、20、21 px 三级。

## 语义结构

1. 输入：环境、几何、物性、终点判据。
2. 共享内核：径向热湿守恒、边界闭合、有限体积、BDF。
3. 四问：同构任务卡展示模型增量与核心输出。
4. 验证：数值一致性、输入与参数、结构假设。

## 连接器语义

- 四类输入经虚线母线汇入共享内核。
- 共享内核向四问扇出。
- 只有 Q2→Q3 使用金色实线，表示未舍入状态继续。
- Q1、Q2、Q4 明确标注原始初态。
- 四问整体向下汇入验证层。
